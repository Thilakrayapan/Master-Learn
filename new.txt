

# 🏗️ 1. FULL ARCHITECTURE (PeakPulse Web → App Evolution)

### 🧱 Architecture Type

👉 **Monolithic Web App**

### Stack:

* **Frontend:** HTML + CSS + JS
* **Backend:** Flask
* **Database:** SQLite

### Flow:

```
Browser (UI)
   ↓
Flask Server (Logic)
   ↓
SQLite Database
```

## 🧩 Prompt 1: Generate Full Flask App

```
You are a senior Python developer.

Create a full Flask web application called "PeakPulse" with the following features:

1. Users can:
   - Add tasks with title and deadline
   - View all tasks
   - Mark tasks as completed

2. System should:
   - Automatically mark tasks as "missed" if deadline passes
   - Trigger a "funny punishment message" when missed

3. Use:
   - Flask (no advanced frameworks)
   - SQLite database
   - HTML templates (Jinja2)
   - Basic CSS styling

4. Structure:
   - app.py
   - templates/
   - static/
   - models.py

5. Include:
   - Database schema
   - CRUD operations
   - Simple UI

Write clean, beginner-friendly code with comments.
```
